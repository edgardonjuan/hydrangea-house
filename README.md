# Hydrangea House

A buildless, one-page static website using the supplied logo and Instagram bio.

## Files

- `dist/index.html`: page content and metadata.
- `dist/styles.css`: responsive layout and colors.
- `dist/assets/hydrangea-house-logo.jpg`: supplied logo.
- `dist/assets/instagram-reference.jpg`: supplied Instagram screenshot, displayed through SVG viewports for three floral images.

Deploy the `dist` directory to any static host. No installation, build step, framework, account, or database is required.

The Instagram handle is `_hydrangeahouse`. The HoneyBook URL in the supplied screenshot is truncated, so inquiry links lead to Instagram. Replace them with the verified full booking URL when it is provided. No phone number, email address, street address, pricing, or service-area claims have been invented.

The gallery source is a 280 × 600 screenshot, so the floral previews are limited in resolution. Replace them with original photos for a sharper gallery.
